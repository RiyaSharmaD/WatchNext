Team

RIYA SHARMA D (1AT24IS165), Python Track

How to run

1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:
    python watchnext.py

Features that work

1. View the available movies and shows.
2. Add new titles with genre and language details.
3. Record watched titles and give ratings.
4. Calculate genre preferences based on user ratings.
5. Recommend up to five unwatched titles.
6. Display trending titles based on views from the last 7 days.
